ChampionCreator/使い方ガイド

はじめての方へ

まずは使ってみよう

ChampionCreatorは、複数の耐久・火力・素早さ条件を同時に満たすSP配分を自動で計算する能力ポイント自動調整ツールです。

OVERVIEW

画面の見方

ChampionCreatorの作業画面は、大きく次の4領域に分かれています。

  1. ①

    調整対象

    調整したいポケモン、性格、特性、持ち物、現在SPなどを入力します。

  2. ②

    仮想敵シナリオ

    相手、技、条件、耐久・火力・素早さの調整種別を入力します。

  3. ③

    候補一覧

    全条件を満たした配分、残りSP、最厳条件、ダメージ詳細を比較します。

  4. ④

    ボックス

    入力中の条件を保存し、読み込みやバックアップを行います。

スマホでは？

スマホ表示では、調整対象と仮想敵シナリオをタッチすると拡大シートで入力できます。候補一覧はトップ画面のまま並び替え、詳細確認、適用、ページ移動ができます。

画面中央のノードは、小さい丸エッジ側が「攻撃を与える側」「素早さを抜く側」、細長いピル型エッジ側が「攻撃を受ける側」「素早さを抜かれる側」を表しています。

WORKFLOW

基本の流れ

  1. 1

    調整対象を入力ポケモン、性格、特性、持ち物、レベル、現在SPを設定します。

  2. 2

    仮想敵シナリオを作成相手ポケモン、技、攻撃側の条件を入力します。

  3. 3

    調整種別を選択耐久調整・火力調整・素早さ調整から目的を選びます。

  4. 4

    計算して候補を比較必要なら複数条件を追加し、候補のPASS内容を確認します。

  5. 5

    候補を適用・保存使いたい候補を調整対象へ反映し、ボックスへ保存します。

TARGET

調整対象

探索のベースになるポケモンを設定します。主な入力項目は、ポケモン名、性格、特性、持ち物、レベル、現在のH/A/B/C/D/S SP、テラスタイプ、ランク、状態異常です。

H/B/Dは耐久候補として同時探索されます。A/C/Sは、入力済みSPや火力調整・素早さ調整で必要になった固定条件として、耐久探索の予算にも反映されます。

SUGGESTIONS

入力サジェスト

技・特性・持ち物の入力候補は、Pokemon Champions Battle Data の Current 使用率を基準に並びます。ヘッダー右上の「シングル」「ダブル」を切り替えると、サジェスト基準と、現在の全攻撃カードの「状況条件 > ルール」を同じ形式へまとめて変更します。

初期値はシングルです。各攻撃カードのルールは一括変更後も個別に選択でき、個別変更からヘッダーへは逆同期しません。次にヘッダーを切り替えると、個別変更を含む現在の全カードへ再度一括適用します。

選択したサジェスト基準だけが同じブラウザに保存されます。条件JSONやボックスから読み込んだルールは読み込み時には上書きされません。ダブル4体の「ふくろだたき」をシングルへ一括変更した場合は、参加上限3体へ整理されます。

技・特性・持ち物は、使用率データに掲載された候補を先頭へ移し、未掲載候補は従来の五十音順で残します。順位や使用率そのものは表示せず、候補の並び順だけに反映します。

性格は、調整対象と各攻撃カードの5×5能力補正表へ実使用率の濃淡を表示します。画面上には詳細な％・順位を追加表示せず、各セルのARIAラベルへ性格、能力補正、選択中のシングル／ダブル使用率、順位を含めます。提供データは上位10件のため、掲載されていない性格は「0%」と扱わず、ARIAラベルでは「上位外／データなし」と区別します。チュートリアル画面では従来の候補順と使用率表示なしの性格表を維持します。

データは1日1回確認し、更新されている場合だけ反映されます。提供元とデータ更新日はアプリ本体のフッターで確認できます。

SCENARIOS

仮想敵シナリオ

シナリオは、調整で満たしたい条件のまとまりです。相手ポケモン、技、性格、特性、持ち物、SP、ランク、天候、フィールド、壁、急所、複数攻撃などを設定できます。

同じシナリオ内の「＋」を押すと、調整列を追加できます。シナリオ名・有効状態・調整種別を共有したまま、相手や技などの条件を追加したい場合に使用します。耐久調整や火力調整では、追加した攻撃を左から順に一連の攻撃として評価します。

「シナリオを追加」を押すと、独立したシナリオ行を追加できます。別の調整種別を設定したい場合や、条件ごとに有効・無効を切り替えたい場合は、新しいシナリオ行を追加してください。

計算時は、最終的に有効になっているすべてのシナリオ行を条件として評価します。一時的に条件から外したい場合は、トグルスイッチで無効化することができます。

DEFENCE

耐久調整

調整対象が相手の攻撃をどれだけ耐えるかを設定します。攻撃側条件、必要耐久回数、必要生存率を入力し、複数条件をすべて満たす配分だけを候補にします。

OFFENSE

火力調整

指定した技で相手を倒すために必要なAまたはCのラインを計算します。必要KO確率を満たすSPが固定条件として耐久候補へ統合されます。

SPEED

素早さ調整

相手ポケモンや任意の実数値を基準に、確定抜き・+〇などのSラインを計算します。条件は、全体へ適用する「共通S条件」、相手側へ適用する「相手S条件」、調整対象側へ適用する「調整対象S条件」に分かれています。

  • 共通S条件：ルール、天候、フィールド、行動順（通常／トリックルーム）を指定します。トリックルームと、おいかぜ（両側）は同時に指定できます。
  • 相手S条件／調整対象S条件：それぞれの状態異常、道具倍率、特性倍率、おいかぜを個別に指定します。まひは通常Sが1/2になり、状態異常時の「はやあし」はSが1.5倍になります。
  • 任意S値：相手の最終Sを直接入力します。この場合は相手ポケモンのS能力や相手S条件を使わず、調整対象側と共通S条件だけを反映します。

道具倍率・特性倍率は通常「自動」で、手動倍率を選ぶと倍率欄が金色になり、欄内へ「手動」を表示します。選択中の持ち物・特性に実際の自動S補正がある場合は、その元入力を暗色＋金枠で示します。手動倍率は自動補正をそのカテゴリだけ置き換える最終Sへの数値上書きで、特性の発動条件や丸め順まで完全に再現するものではありません。「かるわざ」「スロースタート」の発動状態や、「こだいかっせい」「クォークチャージ」でSが上昇する状態を直接指定する専用UIも未対応です。

HP EVENTS

定数ダメージ・回復

攻撃カードの「定数ダメージ・回復」では、直接攻撃の前後に発生する効果を追加できます。対象、発動タイミング、頻度は効果ごとに決まっています。

効果対象発動計算の要点
いのちのたま反動技使用者技の後最大HPの1/10
すなあらし被弾側ターン終了時最大HPの1/16
どく・もうどく・やけど被弾側ターン終了時状態と段階に応じて個別計算
ステルスロック・まきびし被弾側登場時タイプ相性・接地・層数を反映
オボンのみ被弾側条件成立ヒット後同じシナリオ内では1回
たべのこし被弾側ターン終了時最大HPの1/16回復
接触反動技使用者接触ヒット後持ち物・特性ごとに各ヒットで計算

評価する順番

  1. ステルスロック・まきびし
  2. 直接攻撃
  3. ヒットごとの接触反動・オボンのみ
  4. いのちのたま反動
  5. 天候、状態異常、しおづけ、たべのこし

追加した効果は発動する前提で計算し、入力条件と一致しない場合は警告が表示されます。現在HP依存技は、各攻撃・各ヒット時点のHPから自動再計算します。

RESULTS

候補一覧

順位、H/A/B/C/D/S、使用SP、残りSP、最厳条件、詳細を比較できます。「最厳条件」は、その候補にとって一番余裕が少ない条件です。

並び替えでは、総合耐久指数=HBD/(B+D)、物理耐久指数=H*B、特殊耐久指数=H*D を選べます。H/B/D は候補適用後の実数値（H=maxHP()、B=stats.def、D=stats.spd）を使い、SP値の積ではありません。

これらはシナリオ固有のダメージ、タイプ相性、特性、持ち物、HPイベントを含まない並び替え用の補助指標です。検索の合否判定やシナリオ評価は、従来どおり各条件の計算結果を使います。

デスクトップは20件、スマホは5件ずつ表示します。スマホではトップ画面の候補一覧から並び替えとページ移動を行い、候補を開くと詳細がその場に展開されます。使用SPと残りSPのボックス幅は66SPに対する比率で変わり、各候補の最厳条件も表示します。

候補の「適用」を押すと、そのSPが調整対象へ反映されます。適用後に条件を変更した場合は、もう一度「計算開始」を押してください。

BOX & BACKUP

ボックス

入力中の調整対象とシナリオは、操作が止まってから約0.75秒後に「作業中の下書き」として同じブラウザへ自動保存されます。次回起動時は勝手に入力へ戻さず、「下書きを復元」または「下書きを破棄」を選べます。下書きには入力条件だけを保存し、計算結果や候補一覧は保存しません。ガイド内のチュートリアルも保存対象外です。

現在の調整対象、SP、仮想敵シナリオ、有効・無効状態などをブラウザ内へ保存できます。保存名の変更、上書き、複製、削除、空スロットの読み込みに対応しています。

調整対象ボックスへ現在の条件を保存または上書きした場合は、Wordなどの「名前を付けて保存」と同じ確定操作として作業中の下書きを削除し、次に入力を変更するまで「ボックスに保存済み」と表示します。確定保存後は、次回起動時に下書きの復元確認を表示しません。保存内容は調整対象ボックスから明示的に読み込めます。保存済みボックスを作業画面へ読み込むと、その状態が次の下書きになります。調整対象ボックスの空スロットを読み込むと作業中の下書きも破棄されます。バックアップを読み込んだだけでは現在の入力や下書きは変わらず、保存を選んで読み込んだ時点で反映されます。保存容量不足などで自動保存できない場合は、画面のエラーから再試行できます。

ゲスト・未認証、またはM3の移行が完了していない状態の保存は同じブラウザ内に置かれます。別のブラウザ（別のスマホ・PCを含む）へ移す場合は「バックアップを書き出す」「バックアップを読み込む」を利用してください。ヘッダーのGoogleログインは未ログインでも利用でき、M3のone-time migrationが完了した復元済み認証sessionでは、M4のボックス同期、M5のcloud draft、同期状態とアカウント管理の各操作が有効になります。

SYNC-M4 では、調整対象ボックスと仮想敵ボックスの作成・上書き・名前変更・複製・削除・読み込み・バックアップ書き出し・バックアップ読み込みを、UID別のブラウザ保存（outboxを含む）とFirestoreへ同期します。対象はM3の移行が完了した復元済み認証sessionだけで、ゲスト・未認証の操作は従来どおりこのブラウザのlocal-first保存です。保存はまずこのブラウザへ確定し、クラウド同期は起動時、画面focus時、online復帰時、ボックス操作後の再試行で行います。削除はtombstoneとして保持し、競合はLast Write Winsで消さず、local / remoteを要確認状態として保持します。remoteの一部が壊れていても、他の保存を空にせず読めるentryを維持します。

認証済みsessionでバックアップを読み込むと、追加・更新・削除・変更なし、競合コピー、重複除外の件数を確認してから「統合」または「クラウド全体を置き換え」を選べます。読み込めない保存が含まれる場合は警告を表示し、既存データを失う可能性がある置き換えを無効にします。保存0件の正常な空バックアップは、現在の全保存が削除される警告を確認して明示的に置き換えられます。バックアップに残るentryを統合すれば、ブラウザやクラウドで削除済みになったentryも復元できます。

SYNC-M5 のcloud draftは、入力変更後のブラウザ内保存を約0.75秒、操作停止後のcloud deliveryを2秒でqueueします。保存先はuserId + deviceIdごとに分かれ、同じアカウントの別のブラウザの下書きを上書きしません。アカウントあたり有効な下書きは最大10件、保持期間は30日です。期限切れの下書きは起動時、画面focus時、online復帰時、手動操作時にcleanupします。

他のブラウザの下書きは更新日時、ブラウザラベル、入力概要を確認してから、選んだものだけを現在の作業画面へ復元できます。削除も明示操作で行い、復元時にボックスデータは変更しません。pagehide / visibilitychange では同期完了を装わず、未送信mutationをoutboxへ残します。realtime listener、共有ボックス、チュートリアルの保存・同期は対象外です。

ACCOUNT & SYNC

アカウント・同期

ヘッダーのアカウント画面と Googleでログイン は未ログインでも利用できます。ログイン後に SYNC-M3 のone-time migrationが completed になると、今すぐ同期、cloud draft、ログアウト、アカウントデータの書き出し、アカウント削除を操作できます。Googleの「scope」は、アプリがどの情報や機能を使えるかを示すアクセス権の種類です。ChampionCreatorがGoogleログインで受け取るのは、表示名、メールアドレス、プロフィール画像、アカウント識別子です。Google Driveのファイル、連絡先、Gmailのメール本文を見る追加権限は要求しません。

同期状態の表示は、このブラウザのみ、未同期、同期中…、同期済み、オフライン、競合あり、同期エラーの7つです。入力がブラウザへ保存済みでもクラウドへ届いていない場合は「未同期」や「同期エラー」として区別し、保存済みと誤認させません。

アカウントデータの書き出しは、手動同期の後にボックス（syncRecords）とcloud draft（drafts）をサーバーから読み取ります。読み取りエラー、未送信outbox、競合が残る場合は完全な書き出しと表示せず、警告付きの部分書き出しまたは中止になります。JSONにはschema version、書き出し日時、UID、サニタイズしたプロフィール、保存データだけを含め、credentialやtokenは含めません。

アカウント削除では、再認証、同期停止、対象UIDのcloud records列挙・batch削除、空確認、UID専用のローカル保存削除、Firebase Authentication削除の順に処理します。失敗した段階ではAuthenticationを削除せず、原因を表示して再試行できます。最後のAuthentication削除だけが失敗した場合も、クラウドとUID専用ローカル保存は削除済みの状態で再試行できます。通常のボックス・下書き削除はtombstoneとして残り、物理削除はアカウント削除だけが行います。

アカウント削除で消すのはUIDに紐づく保存だけです。ゲスト領域、legacyの championcreator.box.v1 / championcreator.enemy-box.v1、既定サンプルmarkerは残ります。ログイン前からこのブラウザだけにあるデータはアカウント保存と分けて管理されるため、必要ならブラウザのサイトデータ削除や各ボックスの操作で別途削除してください。詳しい取り扱いはプライバシーとデータの取り扱いを確認してください。

INSTALL

ホーム画面へ追加

対応ブラウザでは、ホーム画面やアプリ一覧へ追加してアプリ風に起動できます。Androidはブラウザメニュー、iOS Safariは共有メニュー、PC版Chrome・Edgeはアドレスバーのインストールアイコンから利用できます。

TROUBLESHOOTING

よくある困りごと

  • 候補が出ないシナリオが有効か、必要生存率・KO確率、A/C/Sの固定SPが厳しすぎないかを確認してください。シナリオを1つずつ有効にすると原因を切り分けやすくなります。
  • ポケモン名や技名がうまく入らない候補に表示される名前を選び直すか、表記を変えて入力してください。日本語名・別名・Showdown名を解決できない場合はエラーとして表示します。
  • 計算が遅い条件が多いほど探索に時間がかかります。一時的に不要なシナリオを無効化し、条件を少しずつ追加して確認してください。
  • 実際のゲーム内結果と違うPokemon ChampionsとShowdownの仕様差、未対応データ、特殊処理の差で結果がずれる可能性があります。重要な調整は実機でも確認してください。

注意点

  • ChampionCreatorは非公式のファンツールです。
  • 画像やアイコンは表示用で、計算結果には影響しません。
  • 未対応の技、特性、持ち物、フォームがある場合があります。
  • 計算結果は条件とバージョンを確認し、重要な場面では実機でも確認してください。
  • ゲスト・未認証の保存データはブラウザ内保存なので、バックアップ用途としては完全ではありません。M3移行済みの認証済みsessionでは、M4のUID別ブラウザ保存とFirestore同期、M5のブラウザ別cloud draft、M6のアカウント管理を使います。cloud draftは1アカウント10件まで・30日保持で、復元と削除は明示操作です。
