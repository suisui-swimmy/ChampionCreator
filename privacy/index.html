ChampionCreatorは、入力した調整条件を計算する静的Webアプリです。このページでは、ブラウザ、Firebase、Google Analytics、外部フォントへ何が渡るか、またアカウントデータを書き出す・削除する方法を説明します。

BROWSER STORAGE

ブラウザに保存されるデータ

Googleログインを利用しない場合、入力条件、調整対象ボックス、仮想敵ボックス、作業中の下書き、候補形式の設定はブラウザのlocalStorageへ保存します。Googleログイン後でも、初回統合を保留している間はブラウザ内保存を利用します。これらのデータはブラウザごとに分かれ、クラウドへ自動送信されません。

初回統合を完了した後も、同期用のデータを同じブラウザへ保持します。これには、アカウントの識別子（UID）ごとの保存内容、未送信操作を順番に保持するキュー（outbox）、ブラウザ別クラウド下書き、初回統合の状態が含まれます。計算結果、候補一覧、Workerの状態、チュートリアルは保存・同期しません。

主な保存キーは次のとおりです。UIDやブラウザ識別子（deviceId）の部分は値に応じて変わります。

  • 未ログイン時の保存: championcreator.box.v1、championcreator.enemy-box.v1、championcreator.box.default-example.v1
  • UID別の同期用保存: championcreator.sync.v1.<uid>、championcreator.cloud-draft.v1.<uid>.<device>、championcreator.draft.v1.<uid>.<device>、初回統合の状態（championcreator.migration.v1.<uid>）

ブラウザデータを削除すると、サインイン状態とは別にブラウザ内データが消えることがあります。JSONバックアップを書き出し、ブラウザのプロファイルや利用するスマホ・PCを変更する前に保管してください。

FIREBASE

Firebaseで扱うデータ

Googleログインでは、アプリが使える情報の範囲（scope）として、標準プロフィールだけを利用します。Firebase Authenticationが扱うのは、アカウント識別子（UID）、表示名、メールアドレス、プロフィール画像、ログイン状態です。Google Driveのファイル、連絡先、Gmailのメール本文を見る追加権限は要求しません。

Googleログイン後に初回統合を完了すると、Firebaseのクラウドデータベース（Firestore）のUID配下へデータを保存します。調整対象・仮想敵ボックスはボックス保存用領域（syncRecords）、ブラウザ別の作業中下書きは下書き用領域（drafts）へ保存します。下書きはブラウザごとに分け、同じアカウントの別のブラウザから上書きしません。保存対象は入力条件と同期に必要な管理情報です。計算結果、候補一覧、Workerの状態、チュートリアルは含めません。

通常のボックス・下書き削除では、競合確認や明示的な復元に必要な元データを残したまま、削除済みと記録します（tombstone）。アカウントを削除を選んだ場合だけ、対象UIDのsyncRecordsとdraftsを物理削除します。両方が空になったことを確認してから、最後にFirebase Authenticationのアカウントを削除します。

ChampionCreatorはGoogleの認証情報やアクセストークンを、アプリの保存データや書き出しファイルへ含めません。FirebaseのWebアプリ用設定（Web config）には公開値だけを使います。管理者用認証情報（Firebase Admin credential）、サービスアカウント鍵（service account key）、Google OAuth client secretなどの秘密情報は、ブラウザ配信用bundle、repository、Pages artifactへ含めません。

THIRD-PARTY REQUESTS

Google Analyticsとフォント

アプリ、ガイド、このページではGoogle Analytics 4（測定ID G-VCGTV67QC2）を読み込み、ページ表示などの標準的な利用状況を計測します。ChampionCreatorは、調整条件、ボックス内容、クラウド下書き、UID、認証情報、アクセストークンをAnalyticsイベントへ意図的に送信しません。Google側のCookie、ログ、保持期間、地域処理はGoogleのプライバシーポリシーに従います。ブラウザの設定や拡張機能で外部計測を制限できます。

画面の日本語フォントにはGoogle Fontsの LINE Seed JP を使います。フォントを読み込むと、ブラウザからGoogle Fontsへ通常のHTTPリクエストが送られます。フォント提供元へChampionCreatorの入力条件やアカウントデータを送る処理はありません。

公開版では、Googleログインと同期を保護するため、Firebase Authentication、Firestore、App Checkへのリクエストも発生します。Cloud FirestoreとAuthenticationにはApp Checkを適用しています。Firebaseのサービス提供、ログ、保持はFirebaseのプライバシー情報に従います。

EXPORT

アカウントデータの書き出し

ヘッダーのアカウント画面からアカウントデータを書き出すを選ぶと、最初に手動同期を行います。その後、FirestoreのsyncRecordsとdraftsをサーバーから読み直します。読み取りエラー、未送信操作、競合、破損・未対応データが残る場合は、完全な書き出しとは表示せず、警告付きの部分書き出しまたは中止になります。

JSONには、形式の版（schemaVersion）、書き出し日時（exportedAt）、UID、サニタイズしたプロフィール、調整対象・仮想敵ボックス、クラウド下書きを含めます。認証情報、アクセストークン、秘密鍵、未ログイン時の保存は含めません。ダウンロード用のBlob URLは処理後に破棄します。

このブラウザだけにある未ログイン時のデータは、アカウントデータの書き出し対象外です。必要な場合は各ボックスのバックアップ機能を使って別に退避してください。

DELETE & RETRY

アカウント削除と失敗時の再試行

アカウントを削除を選ぶと、必要に応じてGoogle popupで再認証し、UIDが削除対象と一致することを確認します。その後、同じタブの同期と保存予約を停止します。対象UIDのFirestoreデータを最大450件ずつ削除し、空になったことを再確認してから、UID専用のブラウザ内保存を削除します。Firebase Authenticationのアカウント削除は最後に行います。

再認証、Firestoreの読み取り・削除、空確認、UID専用データの削除のいずれかが失敗した場合は、Authenticationのアカウントを先に削除しません。失敗理由を表示し、同じ画面から再試行できます。最後のAuthentication削除だけが失敗した場合も、ログイン状態を維持して再試行できます。

アカウント削除で消すのはUID専用の保存だけです。ログイン前からこのブラウザだけにあるchampioncreator.box.v1 / championcreator.enemy-box.v1、既定サンプルの削除状態は残します。ブラウザだけのデータを消す場合は、ブラウザのサイトデータ削除や通常のボックス操作を使ってください。

RETENTION & SECURITY

保持期間と安全性

  • ブラウザ別クラウド下書きは1アカウント10件まで、保持期間は30日です。期限切れの下書きは、起動時、画面へ戻ったとき、オンライン復帰時、手動更新時に整理します。
  • ボックスと同期用の管理情報は、ユーザーが削除するまでUIDごとのFirestoreとブラウザ内へ保持します。通常の削除では削除済み記録を使い、アカウント削除時だけ物理削除します。
  • GitHub Pagesの静的フロントからFirebase client SDKを呼びます。ChampionCreator独自のAdminサーバーやGoogle Drive保存はありません。
  • 共有ボックス、リアルタイム共同編集、Google以外のログイン方法は提供していません。

Cloud FirestoreとAuthenticationにはApp Checkを適用し、未検証のアプリからのアクセスを拒否します。Firestore Security Rulesでも、未認証または別UIDからの読み取り・書き込みを拒否します。
